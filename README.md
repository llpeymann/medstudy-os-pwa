# MEDSTUDY OS | سیستم مدیریت هوشمند مطالعه پزشکی

اپلیکیشن PWA فارسی و آفلاین برای مدیریت آمادگی آزمون جامع علوم پایه پزشکی:
برنامه‌ریزی روزانه، مرور فاصله‌دار، تقویم شمسی، تست‌زنی، دفترچه اشتباهات،
تایمر مطالعه و گزارش پیشرفت.

## نسخه منتشرشده

پس از موفقیت workflow، برنامه از این نشانی در دسترس است:

<https://llpeymann.github.io/medstudy-os-pwa/>

## نصب و اجرای محلی

### پیش‌نیازها

- Node.js نسخه ۲۰
- npm نسخه ۹ یا جدیدتر

```bash
# نصب دقیق وابستگی‌های ثبت‌شده در lockfile
npm ci

# اجرای توسعه
npm run dev
# http://localhost:5173

# تست‌های منطق
npm test

# ساخت عادی قابل‌حمل
npm run build

# پیش‌نمایش build
npm run preview
```

## ساخت و اعتبارسنجی مخصوص GitHub Pages

نسخه Pages باید از زیرمسیر `/medstudy-os-pwa/` اجرا شود:

```bash
npm run build:pages
npm run test:pwa
npm run test:e2e:pages
```

- `build:pages` مسیر پایه را روی `/medstudy-os-pwa/` قرار می‌دهد.
- `test:pwa` آدرس assetها، manifest، آیکون‌ها و Service Worker را بررسی می‌کند.
- `test:e2e:pages` برنامه تولیدی را از همان زیرمسیر اجرا می‌کند و ذخیره‌سازی،
  پشتیبان‌گیری، بازیابی، پیمایش، Service Worker و اجرای آفلاین را می‌آزماید.

## انتشار خودکار

workflow مسیر `.github/workflows/deploy.yml` با هر push به `main` اجرا می‌شود:

1. checkout و پیکربندی GitHub Pages
2. `npm ci`
3. آزمون‌های واحد
4. ساخت مخصوص زیرمسیر مخزن
5. اعتبارسنجی artifact و اجرای E2E/Service Worker/offline روی build تولیدی
6. بارگذاری و انتشار با GitHub Pages

برای اولین انتشار، مالک مخزن باید یک‌بار در **Settings → Pages**، بخش
**Build and deployment → Source** را روی **GitHub Actions** قرار دهد. پس از آن
pushهای `main` به‌صورت خودکار منتشر می‌شوند.

## نصب PWA

فایل‌های `public/manifest.webmanifest` و `public/sw.js` نصب و اجرای آفلاین را
فراهم می‌کنند. مرورگرهای پشتیبانی‌شده پس از بازشدن نسخه HTTPS گزینه نصب را
نمایش می‌دهند. Service Worker فقط منابع same-origin داخل زیرمسیر برنامه را
مدیریت می‌کند.

## معماری

| بخش | انتخاب | دلیل |
|---|---|---|
| رابط | React 18 + TypeScript | امنیت نوع و نگه‌داری آسان |
| Build | Vite 5 | build سریع و مسیر پایه قابل تنظیم |
| استایل | Tailwind CSS 4 + متغیرهای CSS | رابط RTL و تم روز/شب |
| فونت | Vazirmatn محلی | نمایش فارسی بدون سرویس خارجی |
| آیکون | Lucide React | سبک و متن‌باز |
| تقویم شمسی | پورت آزموده‌شده jalaali-js | تبدیل واقعی شمسی/میلادی |
| ذخیره‌سازی | IndexedDB با fallback به localStorage | محلی و آفلاین |
| تست | Vitest + Playwright | منطق، رفتار کاربر و PWA |
| انتشار | GitHub Actions + GitHub Pages | HTTPS و انتشار خودکار |

برنامه backend، حساب کاربری یا سرویس همگام‌سازی ندارد و اطلاعات کاربر را به
سرور خارجی ارسال نمی‌کند.

## محل و ایمنی داده

داده‌ها در IndexedDB مرورگر با نام `medstudy-os` ذخیره می‌شوند و اگر IndexedDB
در دسترس نباشد، localStorage استفاده می‌شود. داده‌ها فقط در همان مرورگر و همان
origin باقی می‌مانند. پاک‌کردن داده‌های سایت می‌تواند اطلاعات را حذف کند؛ از
بخش تنظیمات به‌طور منظم نسخه پشتیبان JSON بگیرید.

فایل پشتیبان پیش از بازیابی اعتبارسنجی می‌شود و ورود فایل فقط پس از نمایش خلاصه
و تأیید کاربر، داده فعلی را جایگزین می‌کند.
