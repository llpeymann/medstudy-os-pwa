# MEDSTUDY OS | سیستم مدیریت هوشمند مطالعه پزشکی

اپلیکیشن کاملاً آفلاین برای مدیریت آمادگی آزمون جامع علوم پایه پزشکی؛ قابل اجرا به‌صورت وب/PWA و برنامه دسکتاپ Windows با Tauri 2.
رابط کاربری فارسی، راست‌چین (RTL)، تم روز/شب، مرور فاصله‌دار، تقویم شمسی،
تست‌زنی، دفترچه اشتباهات، تایمر مطالعه و گزارش پیشرفت.

---

## نصب و اجرای محلی

### پیش‌نیازها
- Node.js نسخه ۱۸ به بالا (آزموده‌شده با ۲۰.۲۰)
- npm نسخه ۹ به بالا

### مراحل (در ترمینال، از پوشه پروژه)

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای نسخه توسعه
npm run dev
# مرورگر را به آدرس http://localhost:5173 باز کنید

# ۳. ساخت نسخه نهایی (Production)
npm run build

# ۴. اجرای نسخه نهایی ساخته‌شده
npm run preview
# آدرس: http://localhost:4173

# ۵. اجرای آزمون‌های واحد
npm test
```

### نصب روی موبایل (PWA)
نسخه ساخته‌شده (`npm run build` + `npm run preview` یا هر وب‌سرور استاتیک)
از قابلیت Install روی مرورگر موبایل پشتیبانی می‌کند. فایل‌های
`public/manifest.webmanifest` و `public/sw.js` این قابلیت را فراهم می‌کنند.

### ساخت برنامه Windows 11

پیکربندی Tauri 2 و اسکریپت ساخت Windows در پروژه قرار دارد. روی یک سیستم
Windows 11 که Node.js، Rust و Microsoft C++ Build Tools روی آن نصب است:

```powershell
cd C:\path\to\medstudy-os-desktop
.\scripts\build-windows.cmd
```

این فرمان وابستگی‌ها را دقیقاً از lockfile نصب می‌کند، تست‌ها را اجرا می‌کند،
frontend را می‌سازد و در پایان نصب‌کننده NSIS با پسوند `.exe` را در مسیر زیر
قرار می‌دهد:

```text
src-tauri\target\release\bundle\nsis\
```

برای پیش‌نیازها، مهاجرت امن داده مرورگر و رفع خطاها، راهنمای کامل
[`docs/DESKTOP-WINDOWS.md`](docs/DESKTOP-WINDOWS.md) را بخوانید. نسخه Windows
در این مخزن امضای دیجیتال ندارد و ممکن است SmartScreen هشدار ناشر ناشناس نشان دهد.

## معماری

| بخش | انتخاب | دلیل |
|---|---|---|
| فرانت‌اند | React 18 + TypeScript | امنیت نوع، کیفیت کد |
| Build | Vite 5 | سرعت، پشتیبانی PWA |
| استایل | Tailwind CSS v4 + متغیرهای CSS | تم دوگانه با یک کلاس |
| آیکون | lucide-react | مجوز MIT، سبک |
| نمودار | SVG اختصاصی | بدون وابستگی، تم‌پذیر، RTL |
| تقویم شمسی | پورت دقیق jalaali-js (MIT) | تبدیل واقعی، آزموده‌شده |
| ذخیره‌سازی | IndexedDB (با fallback به localStorage) | پایدار، آفلاین، بومی |
| دسکتاپ | Tauri 2 + WebView2 | پنجره و نصب‌کننده واقعی Windows با backend حداقلی |
| تست | Vitest + Playwright | واحد و عملکردی |

**چرا بک‌اند ندارد:** استفاده تک‌نفره روی یک دستگاه. همگام‌سازی چنددستگاهی
نیازمند سرور و حساب کاربری است و در این نسخه لازم نیست. هیچ داده‌ای به
سرور یا سرویس خارجی ارسال نمی‌شود.

### ساختار پوشه‌ها

```
medstudy-os/
├── index.html                # صفحه اصلی (RTL، فارسی)
├── public/                   # آیکون، manifest، service worker
├── src/
│   ├── types.ts              # مدل داده
│   ├── lib/
│   │   ├── jalaali.ts        # تبدیل شمسی↔میلادی (port jalaali-js)
│   │   ├── dates.ts          # ابزارهای تاریخ و فرمت فارسی
│   │   ├── progress.ts       # محاسبات پیشرفت (منطق خالص)
│   │   ├── reviews.ts        # موتور مرور فاصله‌دار (منطق خالص)
│   │   ├── backup.ts         # خروجی/ورودی JSON + اعتبارسنجی
│   │   ├── db.ts             # لایه IndexedDB
│   │   ├── labels.ts         # برچسب‌های فارسی
│   │   ├── format.ts       # ارقام فارسی و فرمت زمان
│   │   └── id.ts             # تولید شناسه
│   ├── state/store.tsx       # مخزن مرکزی (Context + Reducer)
│   ├── components/           # اجزای UI، نمودارها، تقویم، چارچوب
│   └── pages/                # ۱۰ صفحه اصلی
├── src-tauri/                # پیکربندی، Rust حداقلی، capability و آیکون دسکتاپ
├── scripts/                  # ساخت و اعتبارسنجی Windows
├── tests/                    # تست‌های واحد، عملکردی و پیکربندی دسکتاپ
└── docs/                     # مستندات
```

### محل ذخیره اطلاعات
داده‌ها در **IndexedDB** (نام پایگاه: `medstudy-os`) ذخیره می‌شود. در محیط‌های
بدون IndexedDB، به‌صورت خودکار از localStorage استفاده می‌شود (وضعیت محرک
ذخیره‌سازی در سربرگ نمایش داده می‌شود). نسخه دسکتاپ داده را در پروفایل اختصاصی
WebView2 مربوط به شناسه ثابت `app.medstudy.os` نگه می‌دارد.

مبدأ ذخیره‌سازی مرورگر و Tauri متفاوت است؛ بنابراین داده مرورگر خودکار وارد
برنامه دسکتاپ نمی‌شود. پیش از مهاجرت، در نسخه وب از تنظیمات «تهیه نسخه پشتیبان
(JSON)» را بزنید و همان فایل را در نسخه دسکتاپ با «بازیابی نسخه پشتیبان» وارد
کنید. پاک‌کردن داده مرورگر/WebView یا حذف داده‌های برنامه ممکن است اطلاعات را
از بین ببرد؛ نسخه پشتیبان منظم ضروری است.

### نسخه‌بندی داده
`AppState.version = 1`. هر پرونده پشتیبان شامل نسخه ساختار خود است؛ ورود
فایل با نسخه جدیدتر رد می‌شود.

## راهنمای میان‌بر

- **داشبورد:** شمارش معکوس آزمون، پیشرفت کل و درس‌ها، برنامه امروز، مرورهای موعدرسیده، نمودار هفتگی، آخرین فعالیت‌ها
- **برنامه امروز:** وظایف روزانه، مرورهای امروز، هدف زمانی، وظایف عقب‌افتاده، پیشنهاد جبران
- **دروس و مباحث:** درس ← فصل ← مبحث؛ جست‌وجو، فیلتر، مرتب‌سازی، ویرایش کامل مبحث
- **مرورهای هوشمند:** موعد امروز / عقب‌افتاده / نزدیک / انجام‌شده
- **تقویم:** ماهانه و هفتگی، شمسی یا میلادی، روز استراحت، آزمون
- **تست‌ها و آمار:** ثبت تست، درصد صحیح/غلط/بدون‌پاسخ، روند
- **دفترچه اشتباهات:** دسته‌بندی، حل‌نشده، تبدیل به مرور فوری
- **جلسات مطالعه:** تایمر مقاوم در برابر رفرش، تاریخچه
- **گزارش پیشرفت:** همه شاخص‌ها با/بدون وزن‌دهی صفحات
- **تنظیمات:** نام اپ، تاریخ آزمون، تم، تقویم، الگوی مرور، پشتیبان‌گیری
